# Sistema de Consulta Ciudadana (SRI + ANT + Redis Cloud)

Proyecto full-stack con arquitectura modelada bajo el enfoque **C4** en **IcePanel**.

## Estructura del repositorio
- `backend/`: API REST en Java + Spring Boot (validación SRI Persona Natural/Vehículo y consulta ANT con caché/fallback en Redis Cloud).
- `frontend/`: Aplicación web en React + Vite.
